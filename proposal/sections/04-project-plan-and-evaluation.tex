\subsection*{Dataset and Access}

% \todo{Name the primary dataset, provider, stable access link, license, approximate size, features, and labels if needed. Explain how it will be downloaded or requested, preprocessing, and the unit of analysis. Name a readily available fallback.}

The primary dataset will be the ChangeMyView \cite{tan+etal:16a} data, pulled from the Reddit forum ChangeMyView between January 1st, 2013, and September 1st, 2015 using the Reddit API. The data contains over 3,000 ChangeMyView discussions in JSON format, with original post, comments, and comment attributes (e.g., likes, user, banned, removed\_reason). Comments can be replied to by DeltaBot, indicating that the original poster, or other reader, changed thier view. The dataset is approximately 3 GB in size, and can easily be downloaded directly from the author's personal site.
